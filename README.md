# Северная сага — плейтест

Играть в браузере: **https://zmoomz.github.io/severnaya-saga/**

Прототип стратегии в духе Epic War 4 в скандинавском сеттинге (Godot 4, веб-сборка). В репозитории лежит только собранная игра для плейтестов.

## Управление

- **Q / W / E** или клик по портрету — призвать героя с отрядом.
- **Клик по живому герою, затем по полю** — отвести героя в точку (столб энергии).
- **1–6** — заклинания, ПКМ или Esc — отмена.
- **Z / X / C / V** — команды войску: «К замку», «Оборона», «Марш», «Штурм».
- **A / D** или край экрана — прокрутка поля. Кнопки x1 / x2 / x3 — скорость боя.

## Что посмотреть на плейтесте

- Понятно ли обучение и хватает ли его.
- Темп боя: не слишком ли быстро или медленно.
- Типы урона: видна ли «Разведка» на карточке стадии и помогает ли она собрать армию.
- Отбрасывание, вылазка из замка на Hard, растущее время возрождения героя.
- Где стало скучно, непонятно или слишком сложно.

Прогресс хранится в браузере. Чтобы начать заново, нажмите «Новая игра».
